# QYX MedTech — website

React 18 + Vite + TypeScript. Pages in `src/pages/`, report components in `src/components/analysis/`, API client in `src/services/api.ts`.

- `npm run dev`: http://localhost:5173 with API calls proxied to the backend on port 8000
- `npm run build`: builds `dist/`, which the backend serves at http://localhost:8000

See the main [README](../README.md) for how to run everything.
